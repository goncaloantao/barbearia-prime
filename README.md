# Barbearia Prime 💈

Website moderno e responsivo desenvolvido para uma barbearia, com foco em apresentação profissional, facilidade de navegação e marcação através do WhatsApp.

## 🌐 Demo

https://barbearia-prime-pt.netlify.app

## ✨ Funcionalidades

- Página inicial com destaque visual
- Secção de serviços
- Secção "Sobre Nós"
- Formulário de marcação
- Envio automático dos dados da marcação para WhatsApp
- Contactos e horário
- Menu responsivo
- Design adaptado a computador e telemóvel
- Botão flutuante de WhatsApp
- Navegação suave entre secções

## 🛠️ Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- Netlify

## 📱 Responsividade

O site foi desenvolvido para funcionar corretamente em diferentes tamanhos de ecrã, incluindo computador, tablet e telemóvel.
